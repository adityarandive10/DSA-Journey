\## 🧠 Problem-Solving Methodology



For every problem, I follow this process:



1\. Understand the problem statement.

2\. Identify constraints and edge cases.

3\. Develop a brute-force solution.

4\. Implement the initial approach.

5\. Analyze time and space complexity.

6\. Identify optimization opportunities.

7\. Implement the optimized approach.

8\. Test different cases.

9\. Document and push the solution to GitHub.
